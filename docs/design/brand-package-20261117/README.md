## Design rules
Primary horizontal: symbol followed by CasitaDex. Alternate: CasitaDex followed by symbol. Stacked: symbol above centered CasitaDex.
Maintain proportions and at least one-quarter symbol-height clear space.
Colors: forest #003F30, cream #FFF9EC, gold #C29A62, dark forest #101C17.
Dark reverse artwork includes dark card interiors; use on the specified dark background. Monochrome files also use background-matched interiors: these are not universal one-ink stencils.
The watercolor Home artwork remains an illustration, separate from the scalable vector identity.
Slogan: Your little home for what you want to remember. Use only when space allows.
